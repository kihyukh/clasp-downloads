# Clasp

A desktop workspace for academic papers and Markdown notes.

[Website](https://kihyukh.github.io/clasp/) · [Downloads](https://kihyukh.github.io/clasp/#download) · [Report an issue](https://github.com/kihyukh/clasp-downloads/issues)

Read PDFs beside your notes, highlight and cite passages, connect research ideas,
and collaborate in shared workspaces. Sign in inside the app to get started.

## Install

[Clasp in your browser](https://kihyukh.github.io/clasp/app/) is now at version
1.1.19, with nested block menus, whole-block deletion with Undo, and improved
text colors. Mac and Windows downloads are also at 1.1.19. Earlier installer URLs remain available and unchanged.

- **Mac 1.1.19:** Apple Silicon, Intel and Universal installers. macOS 13 or later. Choose the smaller [Apple Silicon 1.1.19 installer](https://github.com/kihyukh/clasp-downloads/releases/download/v1.1.19/Clasp-1.1.19-mac-arm64.dmg)
  or [Intel 1.1.19 installer](https://github.com/kihyukh/clasp-downloads/releases/download/v1.1.19/Clasp-1.1.19-mac-x64.dmg)
  for your Mac. Check Apple menu → About This Mac to identify your chip. A
  [Universal 1.1.19 installer](https://github.com/kihyukh/clasp-downloads/releases/download/v1.1.19/Clasp-1.1.19-mac-universal.dmg)
  is also available for both. Open the DMG and drag Clasp into Applications.
  The app and disk images are Developer ID signed and notarized by Apple.
- **Windows 1.1.19:** Windows 10 or later, Intel/AMD x64. Run the
  [Windows installer](https://github.com/kihyukh/clasp-downloads/releases/download/v1.1.19/Clasp-1.1.19-windows-x64.exe).
  This release is unsigned, so Windows may show an unknown publisher
  warning. Installation is per-user; uninstalling preserves your workspace data.

SHA-256 checksums: [Apple Silicon 1.1.19](https://github.com/kihyukh/clasp-downloads/releases/download/v1.1.19/Clasp-1.1.19-mac-arm64.dmg.sha256) · [Intel 1.1.19](https://github.com/kihyukh/clasp-downloads/releases/download/v1.1.19/Clasp-1.1.19-mac-x64.dmg.sha256) · [Universal 1.1.19](https://github.com/kihyukh/clasp-downloads/releases/download/v1.1.19/Clasp-1.1.19-mac-universal.dmg.sha256) · [Windows 1.1.19](https://github.com/kihyukh/clasp-downloads/releases/download/v1.1.19/Clasp-1.1.19-windows-x64.exe.sha256).
On Windows, use `Get-FileHash <installer> -Algorithm SHA256`; on Mac, use
`shasum -a 256 <archive>` to compare the downloaded file with its checksum.

Your first sign-in and workspace download need an internet connection. In the
desktop app, previously cached workspaces and notes remain available offline. The
browser app needs an internet connection to open a workspace. The Chrome connector
currently supports macOS; use **Add papers** in Clasp on Windows.

This repository contains official download assets and installation notes.
Application source is maintained separately. Please do not include private papers,
account details, or access tokens when reporting an issue.
